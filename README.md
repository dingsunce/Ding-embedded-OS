Ding embeded os is a tiny operating system that runs on tiny microcontrollers including 8bits mcu,
It can work with any legacy code, no code should be modefied to adapt to this OS 
It has basic OS function, including process management, memory management, timer, task, message management......
It has basic components  including single list, double list, queue...
The rom footprint is 2k, ram footprint can be customized to 3k
